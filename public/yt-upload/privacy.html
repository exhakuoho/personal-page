yt-upload 隱私權政策

最後更新：2026-11-10

用途

yt-upload 是 DesignJarvis 內部工具，只用來把頻道擁有者本人錄製的課程影片與字幕，上傳到擁有者自己的 YouTube 頻道。

存取的資料

經擁有者授權後，本工具使用 YouTube Data API 的以下權限：

  • 上傳影片（youtube.upload）
  • 管理字幕、讀取已上傳影片的處理狀態（youtube.force-ssl）

本工具不會讀取、收集或處理任何其他使用者的資料。

資料儲存與分享

授權憑證只存放在擁有者自己的電腦上，不會上傳到任何伺服器，也不會提供給第三方。

撤銷授權

擁有者可以隨時到 Google 帳戶權限頁面 撤銷本工具的存取權。

本工具使用 YouTube API 服務，須遵守 YouTube 服務條款 與 Google 隱私權政策。
